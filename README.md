# API Testing — Яндекс.Прилавок

## О проекте

Проект посвящён ручному тестированию новой функциональности REST API приложения **Яндекс.Прилавок**.

В рамках проекта проведён анализ требований к новой версии API, разработан чек-лист проверок, выполнено тестирование API в Postman и оформлены баг-репорты по обнаруженным дефектам.

Основная цель тестирования — проверить корректность работы новой функциональности API и соответствие фактического поведения системы требованиям.

---

## Задача

Необходимо было протестировать новую функциональность API Яндекс.Прилавка:

### Работа с наборами

Проверить возможность добавления продуктов в набор:

`POST /api/v1/kits/{id}/products`

### Работа с курьерской службой «Привезём быстро»

Проверить возможность узнать:

- доступна ли доставка;
- стоимость доставки.

Endpoint:

`POST /fast-delivery/v3.1.1/calculate-delivery.xml`

### Работа с корзиной

Проверить:

- получение списка продуктов в корзине;
- добавление продуктов в корзину;
- удаление корзины.

Endpoints:

```text
GET /api/v1/orders/{id}
PUT /api/v1/orders/{id}
DELETE /api/v1/orders/{id}
```

Авторизация в рамках проекта не тестировалась.

Для проверки API использовался **Postman**.

В рамках тестирования выполнялись:

# Результаты тестирования

По результатам тестирования были выявлены дефекты в нескольких функциональных областях.

Основные проблемы:

1. API некорректно обрабатывает невалидные значения `quantity`.
2. API позволяет добавить продукт с отрицательным количеством.
3. API позволяет добавить продукт с `quantity = 0`.
4. API позволяет добавить продукт с `quantity = null`.
5. Удаление существующей корзины завершается ответом `404 Not Found`.
