## BR-1 — Добавление продукта с отрицательным количеством

### Описание

При отправке POST-запроса на добавление продукта в набор с отрицательным значением `quantity` API возвращает успешный ответ `200 OK`.

Отрицательное количество продукта должно считаться невалидным значением.

### Приоритет

🔴 Критический

### Предусловия

1. Создать пустой набор.

### Шаги воспроизведения

1. Отправить POST-запрос на `/api/v1/kits/{id}/products`.
2. Передать в теле запроса отрицательное значение `quantity`.

### Пример запроса

```bash
curl --location 'https://24200b09-0fe9-4797-ab07-dec546e5ba69.serverhub.praktikum-services.ru/api/v1/kits/14/products' \
--header 'Content-Type: application/json' \
--data '{
  "productsList": [
    {
      "id": 1,
      "quantity": -1
    },
    {
      "id": 2,
      "quantity": 2
    }
  ]
}'
```

### Ожидаемый результат

1. Код и статус ответа: `400 Bad Request`.
2. Продукты не добавлены в набор.

### Фактический результат

1. Код и статус ответа: `200 OK`.
2. Продукты добавлены в набор, несмотря на отрицательное значение `quantity`.

### Окружение

`https://24200b09-0fe9-4797-ab07-dec546e5ba69.serverhub.praktikum-services.ru/api/v1/kits/{id}/products`

## BR-34 — Удаление существующей корзины

### Описание

При отправке DELETE-запроса на удаление существующей корзины API возвращает ошибку `404 Not Found`.

Существующая корзина должна быть успешно удалена.

### Приоритет

🔴 Критический

### Предусловия

1. Создать корзину.
2. Убедиться, что корзина существует.

### Шаги воспроизведения

1. Отправить DELETE-запрос на `/api/v1/orders/{id}`.

### Пример запроса

```bash
curl --location --request DELETE 'https://8084f8ea-6173-4107-b5c2-d8f3e86bfd7a.serverhub.praktikum-services.ru/api/v1/orders/2'
```

### Ожидаемый результат

1. Код и статус ответа: `200 OK`.
2. Корзина успешно удалена.

### Фактический результат

1. Код и статус ответа: `404 Not Found`.
2. Корзина не удаляется.

### Окружение

`https://8084f8ea-6173-4107-b5c2-d8f3e86bfd7a.serverhub.praktikum-services.ru/api/v1/orders/{id}`
