# API Endpoints Reference

Документация доступных эндпоинтов для управления продуктами, корзиной и доставкой.

## 📦 Работа с наборами (Kits)
| Метод | Эндпоинт | Описание |
|:---:|:---|:---|
| `POST` | `/api/v1/kits/{id}/products` | Добавление продукта в конкретный набор по его ID |

## 🛒 Работа с корзиной (Cart/Orders)
| Метод | Эндпоинт | Описание |
|:---:|:---|:---|
| `GET` | `/api/v1/orders/:id` | Получение списка продуктов, добавленных в корзину |
| `PUT` | `/api/v1/orders/:id` | Добавление новых продуктов в корзину |
| `DELETE` | `/api/v1/orders/:id` | Полная очистка (удаление) корзины |

## 🚚 Работа с доставкой (Delivery)
| Метод | Эндпоинт | Описание |
|:---:|:---|:---|
| `POST` | `/fast-delivery/v3.1.1/calculate-delivery.xml` | Расчет стоимости и доступности курьерской службы «Привезём быстро» |
